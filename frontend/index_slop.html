Vulkan

Vulkan and Hardware Acceleration (Intel Xe) configuration guide.

arrow_right Vulkan Installation

For Intel Xe graphics (and most modern Intel GPUs), use the vulkan-intel driver.

bash
sudo pacman -S vulkan-intel vulkan-icd-loader

arrow_right Optional: 32-bit Support

Required for Steam and some Wine/Proton games. Ensure multilib is enabled.

bash
sudo pacman -S lib32-vulkan-intel lib32-vulkan-icd-loader

arrow_right Verification

Install vulkan-tools to verify the installation integrity.

bash
sudo pacman -S vulkan-tools
vulkaninfo | grep "deviceType"

arrow_right Hardware Acceleration (VA-API)

Intel Xe graphics use the intel-media-driver for hardware-accelerated video decoding/encoding.

bash
sudo pacman -S intel-media-driver libva-utils
